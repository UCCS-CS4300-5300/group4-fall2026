This program takes an input of locations formatted as an array and prints text output as well as a location
In the future, this will be wrapped in a function to make the system callable in the main app

The system depends on the Ollama app and the llama 3.1 model being installed
Ollama can be installed at https://ollama.com/download/windows
The model used here can be downloaded via command prompt with the command "ollama pull llama3.1:latest" (remove the quotes when actually run)

The specific model used here is a lightweight model made by meta that runs relatively well on weak hardware
This model can be changed out at a later date relatively easily if we need to for some specific reason
