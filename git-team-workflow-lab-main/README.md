# Git Team Workflow Lab

This repository is a small, self-running lab for practicing collaborative Git workflow.

You will work through:

**baseline → parallel branches → pull requests → merge conflict → conflict resolution → bad change → history investigation → old-version inspection → revert → verification**

Open `ACTIVITY.md` and follow the instructions in order.

## Quick start

```bash
python -m pytest
```

The baseline should begin with all tests passing.
